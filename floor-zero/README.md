# קומה 0

משחק אימה פסיכולוגי בגוף ראשון, בדפדפן. אתה טכנאי מעליות. המעלית עוצרת בקומה
שאינה קיימת — והקומה מתחילה לזכור אותך.

המערכת המרכזית במשחק אינה היצור ואינה החידות: היא **מערכת ההקלטה**. כל ביקור
שלך בקומה 0 נשמר — מיקום, מבט, מהירות, כל דלת ומתג שנגעת בהם. בביקור הבא הקומה
מנגנת את ההקלטה הזו דרך דמות שנראית כמוך, והפעולות המוקלטות שלה משפיעות באמת על
העולם. חידת פרק 2 בנויה בדיוק על כך: אי אפשר לפתור אותה לבד.

---

## הפעלה

```bash
cd floor-zero
npm install
npm run dev        # שרת פיתוח — פותח את המשחק בכתובת שמודפסת למסך
```

פקודות נוספות:

```bash
npm run build      # בדיקת טיפוסים + build לתיקיית dist/
npm run preview    # הרצת ה־build המוכן
npm test           # בדיקות אוטומטיות (Vitest)
npm run typecheck  # בדיקת TypeScript בלבד
npm run smoke      # משחק אמיתי מקצה לקצה בדפדפן (ראה למטה)
```

אין צורך בשרת, בחשבון או ב־API חיצוני. הכול רץ מקומית בדפדפן.

| פרק | תוכן |
| --- | --- |
| פרולוג — הקריאה | הרחוב, הלובי, ארון החשמל, המעלית. הצג מראה 0. |
| פרק 1 — המסדרון הריק | מציאת נתיך והחזרת חשמל. הביקור הראשון מוקלט. |
| פרק 2 — החיקוי הראשון | החיקוי מופיע ומנגן את המסלול שלך. חידת השער. |
| פרק 3 — הדירה עם השעונים | ארבעה שעונים על 00:17, טלוויזיה שמקדימה אותך. |
| פרק 4 — חדר הילדים | ציורים שמתארים פעולות עתידיות, חידת הצלילים. |
| פרק 5 — חדר הבקרה | הגילוי, מרדף קצר אחד, ושלושה סופים. |

### שלוש החידות

1. **חידת השער** (פרק 2) — השער נסגר מהר מדי לאדם אחד. יש להפעיל את המתג בדירה
   01 בביקור אחד; בביקור הבא החיקוי משחזר את אותה פעולה מתוך ההקלטה, והשער
   באמת נפתח בזמן שאתה עומד לידו. הפעולה עוברת בדיוק דרך אותה קריאה שהשחקן
   משתמש בה (`InteractionSystem.replay`), ולא דרך אנימציה קבועה.
2. **חידת השעונים** (פרק 3) — ארבעה שעונים, שש שעות אפשריות לכל אחד. הרמזים
   מפוזרים בפתקים, בקלטות ובכתובות על הקירות. הסדר כתוב על המקרר.
   כל שעון נשפט בנפרד: ברגע שהוא מגיע לשעה שהרמז שלו מציין הוא **ננעל** — מסגרת
   ירוקה, קליק, ואי אפשר להזיז אותו יותר. אחד מהם כבר עומד על התשובה שלו ונעול
   מהרגע הראשון, בדיוק כפי שהפתק אומר („אל תיגע בו”). לוחיות ממוספרות 1–4 מתחת
   לשעונים קושרות אותם לסדר שבפתק.
3. **חידת הצעצועים** (פרק 4) — רצף של שישה צלילים. החיקוי מנגן את שלושת
   הראשונים, ואתה משלים את שלושת האחרונים. טעות או איחור **אינם** מאפסים את
   החידה: החיקוי מנגן שוב רק את השלושה שחייבים לך ופותח חלון חדש. אחרי שתי
   טעויות הרמז מוצג מעצמו.

שלוש החידות מציגות רמזים מדורגים שמסתיימים בתשובה עצמה, כך שאי אפשר להיתקע.
המתג „רמזים נוספים בחידות” בהגדרות מקצר את ההמתנה לכל שלב.

### מה עוד נמצא בקומה

מלבד החיקוי — שהוא עותק שלך ומתנהג לפי ההקלטה — יש בקומה שני יצורים שאינם
מחקים כלום. שניהם מתקדמים **רק** כשלא מסתכלים עליהם, וההבדל ביניהם הוא מה קורה
כשכן:

| היצור | הכלל | מה עוצר אותו |
| --- | --- | --- |
| **הזוחל** | נמוך, ארוך־גפיים, מגיע מהקצה החשוך | אור. אם תראה אותו מתחת לנורה עובדת — הוא נסוג לגמרי |
| **הגבוה** | 2.5 מטר, לא זז מול העיניים שלך | רק המבט. אין אור שיעצור אותו, רק לא להוריד ממנו עיניים |

שניהם יכולים לתפוס אותך, ומסך המוות אומר במה נכשלת: „היה חשוך מדי” מול הזוחל,
„הורדת ממנו עיניים” מול הגבוה. הבימוי מרסן אותם בכוונה — זמן צינון ארוך, אף פעם
לא בזמן מרדף, אף פעם לא שניים יחד, ולא לפני פרק 2. יצור שמופיע כל הזמן הוא רעש
רקע; יצור שמופיע פעמיים במשחק שלם הוא מה שזוכרים.

### כשהחיקוי נעמד ומתקלקל

יש מצב שבו החיקוי פשוט **נעמד בקצה המסדרון** ולא זז — פונה אליך, מחכה, ולא
עושה כלום. כל כמה שניות הוא **משתבש בשקט**: הגוף קופץ כמה סנטימטרים לצדדים,
הראש והידיים נזרקים לזוויות לא אנושיות, הוא נמתח, ולרגע הוא פשוט לא שם. בלי
צליל, בלי כתובית, בלי שום דבר שמסב את תשומת הלב — או שבמקרה הסתכלת לשם כשזה
קרה, או שלא תדע שזה קרה בכלל. אחרי כל התקף הוא חוזר בדיוק לאותה עמידה.
`MimicController.glitch()` שומר את התנוחה מראש בדיוק בשביל זה.

### תופעות על־טבעיות

ארבע מהחריגות אינן דברים שזזו כשלא הסתכלת — הן דברים שלא אמורים לקרות: פרצופים
שנדחפים החוצה מבעד לטפט לאורך המסדרון, כתובת שחולחלת מאחורי הקיר, הכיסא שעולה
לתקרה ונשאר תלוי שם לפני שהוא נופל, והרצפה שהופכת למים שחורים ודוממים.

### לאסוף, לא חובה

חמישה **תצלומי פולרויד** מוסתרים בקומה — במסדרון ליד המעלית, ובארבע הדירות.
כל אחד מהם נקרא כמו פתק ומעלה מונה („תצלום 3 מתוך 5”). מי שמוצא את כולם מפתח
תצלום שישי בחדר הבקרה, ומקבל כרטיס נוסף בסוף — בכל אחד משלושת הסופים.
התצלומים אינם חוסמים דבר; אפשר לסיים את המשחק בלי אף אחד מהם.

### הקומה זוכרת אותך

לוח המודעות במסדרון ניתן לקריאה, ומהביקור השני הוא מצטט את **מודל ההתנהגות**
שהמשחק כבר אוסף בשביל החיקוי: לאיזה חדר אתה חוזר, איזו דלת אתה פותח הכי הרבה,
לאיזה כיוון אתה פונה בצמתים, ואם האטת או האצת מאז הביקור הקודם. הטקסטים כתובים
מראש (`src/world/Memory.ts`) והקוד רק בוחר איזה מהם הראיות תומכות בו וממלא את
השם — אין כאן מודל שפה, ואין טקסט מיוצר בזמן ריצה.

### שלושה סופים

כולם נבחרים בחדר הבקרה: **יציאה**, **עצירת המעגל**, **מחיקה**. לאחר "מחיקה"
כפתור ההמשך נעלם, ושם המשחק מהבהב לרגע כ„קומה”.

### ארבע רמות ההתנהגות של החיקוי

1. **מדויק** — משחזר את ההקלטה כמעט במלואה.
2. **פגום** — עוצר יותר מדי זמן, מסובב את הראש, מפספס דלת, ממשיך אחרי סוף ההקלטה.
3. **לומד** — משתמש בדלתות שאתה נוטה להשתמש בהן, מגיע למקומות לפניך, נעלם וחוזר.
4. **מנבא** — בוחר יעד לפי מפת החום שלך, כיוון המבט ומשך השהייה בחדרים.

אין כאן מודל AI: `MimicDirector.predictDestination` מחשב ניקוד משוקלל על גרף
נקודות הניווט. זה פשוט, יציב, וניתן להסבר.

## נכסים

**אין במשחק אף קובץ נכס חיצוני.** הכול נוצר בזמן ריצה:

- **טקסטורות** — נמשכות ב־Canvas 2D (`src/world/Textures.ts`): קיר טיח מצהיב עם
  כתמי רטיבות, רצפת טרצו, אריחי תקרה, דלתות עץ ומתכת, לוח מודעות, תמונה
  משפחתית (עם חמש וריאציות לחריגות), ציורי ילדים, לוחות שעון, מסכי CRT.
- **גיאומטריה** — נבנית מקוביות ומישורים דרך `Builder`, כולל חיתוך פתחים בקירות.
- **סאונד** — מסונתז ב־Web Audio API: זמזום פלורסנט, מנוע מעלית, כבלים, צעדים
  לפי סוג רצפה, נקישות, גשם, רעש טלוויזיה, קלטת, טלפון, נשימות, לחישות.

### החלפת נכס בעתיד

- **טקסטורה** — כל פונקציה ב־`src/world/Textures.ts` מחזירה `THREE.CanvasTexture`.
  להחלפה: טען תמונה עם `THREE.TextureLoader` והחזר אותה במקום. שאר הקוד לא משתנה.
- **מודל** — `src/mimic/MimicController.ts` בונה את הדמות ב־`buildFigure()`.
  להחלפה: טען GLTF והחזר אובייקט עם אותם שדות (`root`, `head`, `arms`, `legs`).
- **סאונד** — הוסף ערך ל־`SOUNDS` ב־`src/audio/AudioManager.ts`. אפשר גם לנגן
  buffer שנטען מקובץ במקום לסנתז; ה־API של `play()` נשאר זהה.

## ביצועים

- מספר קבוע של מקורות אור: אלומת אורות מוקצית דינמית לגופי התאורה הקרובים ביותר
  (3 / 5 / 7 לפי איכות), כך שאורך המסדרון אינו משפיע על עלות הרינדור.
- Post-processing במעבר יחיד (`src/fx/PostFX.ts`) במקום שרשרת composer.
- טקסטורות וחומרים משותפים; UV מותאם לפי גודל הקופסה כדי לשמור על קנה מידה.
- הגבלת Device Pixel Ratio לפי איכות (1 / 1.5 / 2).
- ניקוי מלא של גיאומטריה, חומרים וטקסטורות בכל בנייה מחדש של הקומה.
- הקלטה נדגמת ב־10Hz ונדחסת — ביקור של שש דקות נשאר מתחת ל־40KB.

## בדיקות

```bash
npm test
```

93 בדיקות על המערכות הלוגיות: `PlayerRecorder` (דגימה, חותמות זמן, אירועים,
דחיסה, עצירה והתחלה מחדש, טעינה), `ReplayTrack` (אינטרפולציה כולל זוויות,
הפעלת אירועים בזמן הנכון, שינוי מהירות, הקלטה ריקה), `SaveManager` (שמירה,
טעינה, מחיקה, נתונים פגומים, מעבר בין גרסאות), `AnomalyDirector` (אי־חזרה,
זמני המתנה, סינון לפי פרק, מתח, Seed קבוע), וכן Collision, Nav ותוכנית הקומה.

```bash
npm i -D playwright && npx playwright install chromium   # פעם אחת
npm run build
npm run smoke
```

משחק אמיתי מקצה לקצה: מריץ את ה־build בדפדפן Chromium, מתחיל משחק חדש, משלים
את הפרולוג וחמשת הפרקים, פותר את שלוש החידות, מגיע לסוף, ובודק שאין אף שגיאה
בקונסולה. הוספת `--shots` שומרת צילומי מסך ב־`dist/shots/`, והעברת מספר (1–3)
בוחרת איזה סוף לשחק: `npm run smoke -- 2`.

הבדיקה מפעילה גם דברים שמשחק רגיל לא יגיע אליהם: היא מריצה את **כל** 37 החריגות
ביד ומוודאת שאף אחת אינה זורקת, בודקת שטעות בחידת הצעצועים מחזירה את הרצף במקום
לאפס אותו, ומוודאת ששום פתק, שלט או תצלום אינו קבור בתוך גיאומטריה מוצקה —
הקירות בעובי 0.18 מ׳ וממורכזים על הקואורדינטה שלהם, כך שלוח שנתלה על
הקואורדינטה עצמה נבלע לגמרי ופשוט לא מצויר.

Playwright אינו תלות של הפרויקט עצמו — הוא נדרש רק לבדיקה הזו, כדי ש־
`npm install` יישאר קל.

המערכות מדברות ביניהן דרך `EventBus` ומקבלות `GameContext` — אין תלות ישירה בין
מודולים.

## שפה

ברירת המחדל היא עברית בכיוון ימין־לשמאל. ניתן להחליף לאנגלית בהגדרות → תצוגה →
שפה. כל המחרוזות נמצאות ב־`src/data/localization.ts` וב־`src/data/dialogue.ts`.

## מגבלות ידועות

- המראה במעלית אינה השתקפות אמיתית — היא משטח כהה עם צללית שמופיעה בחריגות
  מסוימות. מראה אמיתית דורשת מעבר רינדור נוסף.
- אין קול דיבור מוקלט. הקלטות התחזוקה מוצגות ככתוביות מעל רעש קלטת מסונתז.
- הקומה בנויה מתוכנית קבועה עם וריאציות בין ביקורים, ולא נוצרת פרוצדורלית
  מחדש בכל פעם.
