## 10.1 עקרונות עיצוב

| # | עיקרון | יישום |
|---|--------|-------|
| 1 | **הניצוץ הוא הגיבור** | 70% ממסך הבית הוא הכרטיס. כל השאר משני. |
| 2 | **שקט, לא ריק** | מרווח נדיב, טיפוגרפיה חמה, מרקם עדין — לא מינימליזם קר. |

## 10.2 שפה ויזואלית

**מטאפורה מרכזית:** *נייר וגחלת* — הכרטיס הוא דף בספר; הניצוץ הוא האור שנופל עליו.

**כיוונים שנפסלו:**
- ❌ "אפליקציית פרודוקטיביות" (כחול/אפור, קר, תאגידי)
- ❌ "רווחה רוחנית" (סגול/ורוד, גרדיאנטים, מיסטי)
- ❌ "גיימיפיקציה" (צבעים רוויים, תגים, קונפטי בכל מקום)

**הכיוון שנבחר:** *עורכי, חם, שקט* — כמו ספר שירה יפה שגם עובד כאפליקציה.

## 10.6 אייקונוגרפיה

- **סט:** Phosphor Icons (משקל Regular ל‑UI, Fill למצב פעיל). קוד פתוח, סגנון עגול ורך.
- **קו:** 1.75px, פינות מעוגלות, גריד 24×24.
- **אייקוני ליבה מותאמים אישית** (מצוירים ידנית, לא מהסט):
  - `spark` — ניצוץ אסימטרי בעל 4 קרניים (הלוגו)
  - `ember` — גחלת עגולה עם זוהר
  - `book` — ספר פתוח עם ניצוץ בין הדפים
  - `streak` — להבה רכה, לא אגרסיבית
- **מצבים רגשיים:** 6 אייקונים מצוירים ידנית, קו בלבד, ללא פרצופים
  (פרצופים מכתיבים פרשנות — צורות מופשטות מאפשרות הזדהות).

**איורים:** קו יחיד עם כתם צבע אחד (ember או moss). ללא דמויות אנוש עם פנים.
מצבים ריקים מקבלים איור; שגיאות לא (הן מקבלות טקסט + פעולה).

## 10.7 אנימציות ותנועה

**עקומות תזמון:**
```
ease-out-quint:  cubic-bezier(0.22, 1.00, 0.36, 1.00)   ← כניסות
ease-in-out:     cubic-bezier(0.65, 0.00, 0.35, 1.00)   ← מעברים
spring-soft:     damping 18, stiffness 180, mass 1      ← אינטראקציות
```

### אנימציות מפתח

**1. `spark-reveal` — חשיפת הניצוץ היומי** *(האנימציה החתומה של המוצר)*
```
0ms      הכרטיס: scale 0.94, opacity 0, translateY 12
0-120    זוהר רך מתפשט ממרכז המסך (radial, ember, opacity 0→0.18)
120-540  הכרטיס: scale→1, opacity→1, translateY→0   [ease-out-quint]
200-900  8-14 חלקיקי אור עולים ומתפוגגים (Skia)     [stagger 40ms]
420      טקסט הכותרת: fade-in + translateY 6→0
540      הצעד: fade-in
620      שורת התגובה: fade-in + scale 0.96→1
```
משך כולל 900ms. **תמיד ניתן לדילוג בהקשה.**

**2. `ignite` — סימון "עשיתי"**
```
0ms    הכפתור מתכווץ ל-0.92 · haptic: success
80ms   הכפתור מתמורף לעיגול עם ✓ [spring-soft]
160ms  גל אור יוצא מהכפתור אל הכרטיס
300ms  הכרטיס מקבל מסגרת moss עדינה
360ms  מונה הרצף מתקתק +1 [spring-soft] · הלהבה פועמת פעם אחת
```
**קונפטי:** רק בימים 7, 30, 100, 365 — ולא יותר מ‑1.2 שניות.

**3. `card-to-detail`** — Shared element transition. הכרטיס גדל למסך מלא, הטקסט נשאר במקומו ומתרחב (400ms).

**4. `mood-select`** — האייקון הנבחר גדל ל‑1.15 וחוזר; האחרים דוהים ל‑0.4 opacity (220ms).

**5. `streak-flame`** — לולאה עדינה: scale 1↔1.04, opacity 0.9↔1, 2.4 שניות, `ease-in-out`. עוצרת אחרי 3 מחזורים.

**6. `page-turn` (ספר הניצוצות)** — מעבר בין חודשים במחווה, עם עקומת דף עדינה ב‑Skia.

**7. `pull-to-refresh`** — ניצוץ קטן שמתמלא ככל שמושכים; לא ספינר סטנדרטי.

### חוקי תנועה
- **מקסימום 900ms** לכל אנימציה. מעל זה זה מטרד.
- **`prefers-reduced-motion` / הגדרת נגישות** → כל התנועה מתחלפת ב‑fade של 150ms. חלקיקים כבויים.
- **Haptics:** `success` על "עשיתי" · `light` על ניווט · `warning` על שגיאה · אף פעם לא על טעינה.
- אנימציה אף פעם לא חוסמת אינטראקציה.

## 10.8 נגישות (WCAG 2.2 AA)

| דרישה | יישום |
|-------|-------|
| ניגודיות | 4.5:1 טקסט · 3:1 טקסט גדול ורכיבי UI — נבדק בכל טוקן |

| ניווט מקלדת | תמיכה מלאה (חיצוני/iPad) |
| הפחתת תנועה | הגדרה עצמאית באפליקציה + כיבוד הגדרת המערכת |
| ניגודיות גבוהה | ערכה חלופית עם גבולות מודגשים |
| עיוורון צבעים | קטגוריות מסומנות באייקון + טקסט, לא רק בצבע |
| קול | הקראת ניצוץ (TTS) גם כפיצ'ר נגישות (לא רק Pro) |
| שפה | `lang` ו‑`dir` נכונים לכל אלמנט לצורך הגייה נכונה |

## 10.9 RTL — תכנון מפורש

| נושא | כלל |
|------|-----|
| פריסה | `flex-start`/`flex-end` בלבד. אף פעם לא `left`/`right` קשיח |
| אייקונים כיווניים | חץ "חזור", התקדמות, שיתוף — משתקפים |
| אייקונים לא‑כיווניים | שעון, לב, ניצוץ — **לא** משתקפים |
| מספרים ותאריכים | תמיד LTR בתוך הקשר RTL (בידוד דו‑כיווני) |
| מחוות | החלקה "חזור" מהקצה **הימני** בעברית |
| אנימציות | translateX מוכפל ב‑`-1` ב‑RTL |
| כרטיס שיתוף | תבניות נפרדות ל‑RTL/LTR |
| בדיקות | כל מסך נבדק בשתי הכיווניות ב‑CI (screenshot tests) |

## 10.11 מצבים ריקים ושגיאות — קופי

| מצב | טקסט |
|-----|------|
| ספר ריק | **"כאן ייבנה הספר שלך."**<br/>הניצוץ של היום כבר בפנים. עוד 364 בדרך. |
| אין רשת | **"אין חיבור — והכל בסדר."**<br/>הניצוץ שלך שמור במכשיר. |
| תובנות מוקדם מדי | **"עוד 3 ימים."**<br/>אנחנו צריכים קצת יותר נתונים לפני שנגיד לך משהו אמיתי. |
| חיפוש ללא תוצאות | **"לא מצאנו."**<br/>נסה מילה אחרת, או עיין לפי קטגוריה. |
| שגיאת שרת | **"משהו נתקע אצלנו."**<br/>הניצוץ של היום מחכה במכשיר. ננסה שוב ברקע. |
| הסתיים ניסיון | **"הניסיון הסתיים. הספר שלך נשאר."**<br/>אפשר להמשיך בחינם, או לפתוח הכל שוב. |

**עקרונות קופי:** אף פעם לא "אופס!" · אף פעם לא מאשימים את המשתמש ·
תמיד יש פעולה אחת ברורה · טון שקט ובוגר.
