## 3.2 S1 — מסך הבית (הניצוץ היומי)

**מטרה:** למסור את הניצוץ ולאפשר תגובה תוך פחות מ‑15 שניות. זהו 80% מהשימוש באפליקציה.

### פריסה (מלמעלה למטה)

```
┌──────────────────────────────────┐
│  🔥 12          יום שלישי, 11.8  │  ← Header: רצף + תאריך
│                                  │
│         [ צ׳יפ קטגוריה ]         │  ← "תנועה · 2 דקות · מיקרו"
│                                  │
│   ┌────────────────────────┐     │
│   │                        │     │
│   │   כותרת הניצוץ         │     │  ← Serif 28pt, מרכז
│   │                        │     │
│   │   גוף הניצוץ — 2־3     │     │  ← Sans 17pt
│   │   שורות מקסימום        │     │
│   │                        │     │
│   │  ── הצעד ──            │     │  ← מפריד עדין
│   │  ▸ צעד הפעולה המדויק   │     │  ← מודגש, בר־ביצוע
│   │                        │     │
│   └────────────────────────┘     │  ← כרטיס הניצוץ
│                                  │
│   ✓ עשיתי   ⏳ לא היום   ✕ לא לי │  ← שורת תגובה
│                                  │
│   ☆ שמור    ↗ שתף    ⟳ עוד אחד  │  ← פעולות משניות
└──────────────────────────────────┘
```

### רכיבים
| רכיב | פירוט |
|------|-------|
| `StreakBadge` | מספר + להבה. לחיצה → הסבר רצף + ימי הקפאה שנותרו |
| `SparkCard` | הרכיב המרכזי. מעבר לפרטים בהקשה. Shared‑element transition |
| `CategoryChip` | קטגוריה · תקציב זמן · מידה. לחיצה → סינון בספר |
| `ResponseRow` | 3 כפתורים. Haptic feedback שונה לכל אחד |
| `SecondaryActions` | שמירה / שיתוף / reroll (עם מונה שימושים נותרים) |

### מצבים (States)
| מצב | תצוגה |
|-----|-------|
| **טעינה ראשונה** | Skeleton של הכרטיס + מיקרו‑אנימציית ניצוץ (≤ 400ms) |
| **מוכן** | הניצוץ עם אנימציית `spark reveal` |
| **כבר בוצע היום** | הכרטיס עם סימון ✓, טקסט "נתראה מחר" + מונה לניצוץ הבא |
| **לא מקוון** | הניצוץ מהקאש + באנר עדין "לא מחובר — הכל שמור מקומית" |
| **אין קאש + אין רשת** | ניצוץ evergreen מובנה באפליקציה (50 פריטים מוטמעים) |
| **שגיאת שרת** | ניצוץ evergreen + retry שקט ברקע |
| **יום ראשון (חדש)** | ניצוץ מ"קשת הפתיחה" (starter arc) + tooltip על כפתורי התגובה |
| **אחרי חצות** | רענון אוטומטי; אם האפליקציה פתוחה — מעבר רך לניצוץ החדש |

### קצוות (Edge Cases)
- שינוי אזור זמן בטיסה → הניצוץ **לא** מתחלף באמצע היום; מתחלף רק אחרי 04:00 מקומי.
- שני מכשירים → סנכרון סטטוס ביצוע דרך `last_write_wins` עם חותמת שרת.
- משתמש שסימן "לא בשבילי" → הכרטיס מתחלף מיד לחלופה (זה גם ה‑reroll החינמי שלו).

## 3.3 S1a — ניצוץ מורחב

נפתח בהקשה על הכרטיס. מכיל:
- הניצוץ המלא + **"למה קיבלת את זה"** (שקיפות AI): *"כי סימנת מטרה 'יותר תנועה' וכי אתה נוטה לבצע ניצוצות בבוקר."*
- **הרחבה** (2–4 משפטים): רקע, מקור הרעיון, וריאציה קלה יותר.
- **טיימר מובנה** אופציונלי לפי תקציב הזמן (60s / 5m / 15m) עם צליל עדין.
- **הערה אישית** — שדה טקסט חופשי שנשמר בספר.
- דיווח תוכן (M3).

> **שקיפות ה‑AI היא פיצ'ר אמון מרכזי** ולא נספח. היא גם מפחיתה "לא בשבילי" כי המשתמש מבין את ההיגיון.

---

## 3.4 S1b — צ׳ק‑אין רגשי (Bottom Sheet)

- מוצג פעם ביום, לפני חשיפת הניצוץ, **רק אם המשתמש הפעיל אותו** (ברירת מחדל: פעיל, ניתן לכיבוי).
- 6 אייקוני מצב ברשת 3×2 + סליידר אנרגיה.
- "דלג" תמיד גלוי ולא מודגש בשלילה.
- אחרי בחירה: מיקרו‑אנימציה של המשך + הניצוץ מותאם למצב.

**כלל בטיחות:** בחירת "מוצף" או "שטוח" → המנוע מגביל את מרחב המועמדים למידה מיקרו וטון עדין, ואוסר על תוכן אתגרי/ביצועי.

## 3.5 S2 — ספר הניצוצות

### S2a · ציר זמן (ברירת מחדל)
כרטיסים מקובצים לפי חודש, עם מפריד תאריך דביק (sticky).
כל שורה: תאריך · כותרת · תג קטגוריה · אינדיקטור סטטוס (✓ / ⏳ / ✕).

### S2b · רשת ולוח חום
- לוח חום שנתי (בסגנון GitHub contributions) בגוונים חמים.
- הקשה על יום → הניצוץ של אותו יום.
- מעל הלוח: "42 ניצוצות בוצעו · הרצף הארוך ביותר: 19 ימים".

### S2c · שמורים ואוספים
רשימת אוספים + אוסף "שמורים" מובנה. גרירה לסידור. שיתוף אוסף כתמונה (`Plus`).

### S2d · חיפוש וסינון
- שדה חיפוש (`Plus`) — חיפוש טקסט מלא + חיפוש סמנטי ("משהו על להתחיל כשאין כוח").
- מסננים: קטגוריה, טיפוס, סטטוס, מצב רגשי בזמן קבלה, טווח תאריכים.

### מצבים
| מצב | תצוגה |
|-----|-------|
| ריק (יום 1) | איור + "כאן ייבנה הספר שלך. ניצוץ ראשון כבר בפנים." |
| Free בגבול 30 יום | הפריטים הישנים מטושטשים עם CTA עדין ל‑Plus (ללא חסימה אגרסיבית) |
| טעינה | Skeleton של 6 שורות |

## 3.6 S3 — תובנות ומסעות

### S3a · תובנה שבועית
כרטיס ראשי + 3 מיני‑גרפים:
1. **ביצוע לפי יום** (עמודות 7 ימים)
2. **ביצוע לפי שעה** (מפת חום שעתית)
3. **קטגוריות מובילות** (3 שורות עם אחוזים)

מתחת: פסקת תובנה מנוסחת ב‑AI + **פעולת כוונון אחת** בכפתור
("העבר את ההתראה ל‑08:40" / "הפחת ניצוצות כספים").

### S3b · מסעות פעילים
כרטיס מסע עם התקדמות (יום 4 מתוך 14), הצעד של היום, ואפשרות להשהות (לא לבטל — **השהיה היא ברירת המחדל**).

### S3c · ספריית מסעות
רשת של מסעות עם תמונת נושא, משך, ורמת מאמץ.

**מצב ריק (פחות מ‑7 ימי נתונים):** "עוד 3 ימים ונוכל להראות לך דפוסים אמיתיים" + מונה.

## 3.7 S4 — פרופיל

- אווטאר/ראשי תיבות · שם · תאריך הצטרפות.
- **סטטיסטיקות ליבה:** סה"כ ניצוצות · בוצעו · רצף נוכחי · רצף שיא · קטגוריה מובילה.
- **תג מסע:** "40 ימים עם DailySpark".
- ניווט אל: התאמה אישית (S5) · הגדרות (S6) · מנוי (S7).
- כפתור **"כוונן את המנוע"** — קיצור ל‑S5d.

## 3.8 S5 — התאמה אישית

מסך זה הוא "לוח הבקרה" של המשתמש על ה‑AI. חשוב שירגיש **שליטה ולא טופס**.

| תת‑מסך | תוכן | UI |
|--------|------|-----|
| **S5a מטרות** | עד 3 (Free) / ∞ | כרטיסים הניתנים לגרירה לסידור עדיפות + שדה מטרה חופשית |
| **S5b תחומי עניין** | 12 תחומים | צ'יפים תלת‑מצביים: `חשוב לי` / `מעניין` / `לא` |
| **S5c הרגלים** | הרגל + תדירות | שורה עם בורר תדירות (יומי / 3× שבוע / שבועי) |
| **S5d טון ומידה** | טון, תקציב זמן, אנרגיה טיפוסית | סליידרים + תצוגה מקדימה **חיה** של ניצוץ לדוגמה בטון הנבחר |
| **S5e נושאים חסומים** | רשימת נושאים | צ'יפים להסרה + חיפוש נושא |

**קריטריון קבלה:** כל שינוי משפיע על הניצוץ של **מחר** (ומיידית על "עוד אחד"), עם הודעה מפורשת:
*"עודכן. הניצוץ של מחר כבר יביא את זה בחשבון."*

## 3.10 S7 / M1 — מנוי ו‑Paywall

**מבנה Paywall:**
1. כותרת ערך (לא רשימת פיצ'רים): *"ניצוץ שמכיר אותך באמת."*
2. 3 שורות ערך עם אייקונים.
3. בורר תוכניות (שנתי מודגש עם "חסוך 50%").
4. "התחל 7 ימי ניסיון" — CTA יחיד.
5. שורת אמון: "ביטול בקליק · ללא חיוב אוטומטי בלי תזכורת 48 שעות מראש".
6. שאלות נפוצות מתקפלות.

**נקודות הצגה:** אחרי יום 7 (ולא לפני) · בלחיצה על פיצ'ר נעול · בגבול ההיסטוריה · אחרי milestone של 30 ימים.
**איסור:** לא יותר מ‑2 חשיפות שבועיות; אף פעם לא לפני הניצוץ היומי.

## 3.11 M4 — כרטיס תמיכה (רשת ביטחון)

מוצג ב‑S1 במקום הניצוץ הרגיל (עם אפשרות "המשך לניצוץ") כאשר מופעל F‑32.

- טון: שקט, ללא אייקונים דרמטיים, ללא אדום.
- תוכן: משפט מכיל אחד + 2 קווי סיוע מקומיים לפי מדינה (ישראל: ער"ן 1201, סה"ר) + "אני בסדר, תודה".
- **לעולם לא**: אבחון, "נראה שאתה בדיכאון", או המלצה רפואית.

## 3.12 עקרונות ניווט רוחביים

1. **חוק שתי ההקשות** — כל מסך נגיש בשתי הקשות מהבית.
2. **הבית תמיד חוזר לניצוץ** — הקשה על טאב הבית מאפסת גלילה וסוגרת מודלים.
3. **RTL‑first** — כל הניווט, המחוות והאנימציות מתוכננים לעברית ומשקפים ל‑LTR.
4. **אין מסך מבוי סתום** — לכל מצב שגיאה יש פעולה אחת ברורה.
5. **Deep links** — `dailyspark://spark/today`, `dailyspark://book`, `dailyspark://insights/weekly`, `dailyspark://settings/notifications`.
